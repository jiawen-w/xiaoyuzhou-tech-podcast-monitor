## 更新机制

- 豆包定时任务「小宇宙科技播客监测」每天 09:30 触发
- 抓取各频道小宇宙主页最新单集 → 与历史去重 → 新增条目追加到 `episodes.json` 并同步更新本仓库 → 自动 push，GitHub Pages 即时刷新
- 页面按发布日期倒序分组，支持按频道筛选

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | GitHub Pages 主页面（读取 `episodes.json` 渲染） |
| `episodes.json` | 结构化单集数据，每日追加 |
| `fetch_xiaoyuzhou.py` | 抓取脚本：拉取各频道主页 `__NEXT_DATA__` 解析最新单集 |
